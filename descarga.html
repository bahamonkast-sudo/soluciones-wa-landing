Descarga la aplicación

Sigue estos pasos para obtener el instalador desde Mega:

  1. Pulsa Descargar ahora y completa tus datos.
  2. Se abrirá WhatsApp para que confirmes el envío del mensaje de evaluación.
  3. Cuando pasen 20 segundos, aparecerá el botón naranja para continuar a Mega.
  4. En Mega, pulsa Descargar y guarda el archivo en tu dispositivo.

WhatsApp requiere que confirmes el envío. El formulario no transmite ni guarda tus datos; el mensaje prellenado solo dice: “Quiero Evaluar la aplicación”.
