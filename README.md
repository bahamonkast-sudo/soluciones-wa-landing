# Landing de Soluciones WA

Página estática construida en HTML, con el video y la portada del robot como archivos locales del proyecto.

## Archivos

- `landing_wa_rediseno.html`: página principal.
- `robot-hero.mp4`: animación interactiva del hero.
- `robot-hero-poster.jpg`: imagen de portada mientras carga el video.

## Publicación

Mantén el repositorio privado si quieres restringir el acceso al código fuente. Si más adelante publicas la web para clientes, el navegador necesariamente recibirá el HTML, los estilos, scripts e imágenes que necesita para mostrarla; evita guardar claves o información secreta en esos archivos.

El widget de Facebook y las fuentes/iconos externos necesitan conexión a internet. Para que el widget funcione de forma consistente, sirve la página por HTTPS.
